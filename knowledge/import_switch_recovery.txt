Register calls to imported functions

The original code often loads an import slot into a register and reuses it.
The decoder now follows exact 32-bit register copies through the decoded control
flow. Incoming paths must agree. Other writes discard the value; calls discard
it unless the native kernel ABI or a checked preservation contract retains it.
Only imports read directly from a verified absolute IAT slot receive this tag.
Unknown object methods and stack aliases do not become imported calls.
